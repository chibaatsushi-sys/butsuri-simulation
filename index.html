ばねで打ち出される小球のシミュレーション

ばねを l だけ縮めて放すと、小球は単振動しながら加速し、自然長の位置(t = T/4)でばねから離れて等速直線運動をする。小球をドラッグして縮みを変えたり、x-t / v-t / a-t グラフや「もしも離れなかったら」モードで単振動と比較したりできる。

円運動する車のシミュレーション

円筒面を昇る車が、最高点まで昇って宙返りできる条件を実験できる。初速度 v₀ = √(〇×gR) の〇を変えて、「v = 0 で逆戻り」「N = 0 で面から離れて放物運動」「一周成功」の3パターンを、N–α・v–α グラフと連動して観察しよう。

床A・台B・小球Cのシミュレーション(校内模試の問題)

台Bの上で、ばねで打ち出された小球Cが斜面と円弧RTUを進む。問1「台Bが固定」と問2「台Bが自由に動ける」を切り替えて、運動量保存・重心が動かないこと・台B上の観測者(非慣性系)から見た運動まで実験できる。
